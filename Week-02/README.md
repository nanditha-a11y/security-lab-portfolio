## 🧪 Project — Wireshark Packet Analysis

Performed a beginner-level investigation of real network traffic using Wireshark.

### Investigation Highlights

- Identified a local BPL Android TV device
- Investigated mDNS service discovery
- Identified Google Cast service advertisements
- Correlated a Google Cast service with TCP port 8009 using an SRV record
- Analysed TCP communication between local devices
- Examined TLS 1.2 encrypted application data
- Investigated DNS resolution for a Microsoft endpoint
- Correlated DNS resolution with subsequent TCP/TLS traffic
- Analysed TCP conversation statistics
- Examined the protocol hierarchy of the capture
