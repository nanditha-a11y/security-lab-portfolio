## What I Learned

I learned how devices communicate over the Internet and what happens when a user enters a website address into a browser.

The process involves:

1. The device connects to a local network.
2. DNS translates a domain name into an IP address.
3. The browser establishes a connection with the server.
4. TCP/UDP handles transport of data.
5. HTTP/HTTPS is used for web communication.
6. The server sends a response back to the browser.
7. The browser processes the response and displays the website.
