## OSI Model

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

## TCP vs UDP

### TCP

- Connection-oriented
- Reliable
- Uses acknowledgements
- Ensures packets arrive correctly
- Uses a three-way handshake
- Examples: HTTPS, SSH, FTP

### UDP

- Connectionless
- Faster
- No guarantee of delivery
- No three-way handshake
- Examples: DNS, VoIP, online gaming

## Security Relevance

Understanding OSI and TCP/UDP helps in analysing network traffic, identifying protocols, understanding attacks, and using tools such as Wireshark and Nmap.
