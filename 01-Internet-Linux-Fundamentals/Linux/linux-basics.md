# Linux Basics — Part 1

## Topics Covered

- Linux file system
- Navigating directories
- Creating and removing files and directories
- Reading files
- Basic text editing
- Practicing Linux using WSL2

## Commands Practiced

### pwd

Displays the current working directory.

`pwd`

### ls

Lists files and directories.

`ls`

`ls -la`

### cd

Changes the current directory.

`cd /home`

`cd ..`

`cd ~`

### mkdir

Creates a directory.

`mkdir test`

### rmdir

Removes an empty directory.

`rmdir test`

### rm

Removes a file.

`rm file.txt`

### cat

Displays the contents of a file.

`cat file.txt`

### echo

Displays text or writes text to a file.

`echo "Hello"`

`echo "Hello" > file.txt`

### cp

Copies a file.

`cp file.txt backup.txt`

### mv

Moves or renames a file.

`mv old.txt new.txt`

### nano

Opens a simple terminal text editor.

`nano notes.txt`
